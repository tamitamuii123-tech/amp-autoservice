# AMP Auto Service — CV. Arshaka Mandiri Perkasa

Website resmi CV AMP (General Supplier & Engineering Services) dan AMP Auto Service, Banjarmasin.

- Website: https://tamitamuii123-tech.github.io/amp-autoservice/
- Akun pelanggan: https://tamitamuii123-tech.github.io/amp-autoservice/akun.html

Repository ini hanya berisi **frontend statis** (HTML, CSS, JavaScript, gambar) yang disajikan GitHub Pages.
Login, booking, riwayat servis, konsultasi, dan data pelanggan diproses oleh AMP Server milik bengkel,
bukan oleh repository ini. Tidak ada database, kata sandi, atau kunci rahasia di sini.

Branch `main` dibuat ulang otomatis setiap publikasi oleh alat internal bengkel; jangan mengedit file di GitHub secara langsung.
